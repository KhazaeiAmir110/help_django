# 📚 مجموعه پروژه‌های آموزشی Django

این پروژه یک **مجموعه از تمرین‌ها و پروژه‌های آموزشی در حوزه وب با استفاده از فریم‌ورک Django** است.
هدف اصلی این پروژه، **افزایش توانمندی در برنامه‌نویسی وب و آشنایی با ابزارها و تکنیک‌های مختلف توسعه وب** بوده است.

هر شاخه (Branch) در این مخزن به یک موضوع خاص اختصاص دارد و شامل پروژه‌ها یا مثال‌های آموزشی مستقل می‌باشد.
این ساختار به کارفرما این امکان را می‌دهد که **تنوع مهارت‌ها و تجربه عملی شما در زمینه Django و توسعه وب را مشاهده کند**.

---

## 🚀 اهداف و قابلیت‌ها

* ✅ **تمرین با مفاهیم اصلی Django**: مدل‌ها، ویوها، قالب‌ها، فرم‌ها و مدیریت پایگاه داده
* ✅ **آشنایی با ابزارها و تکنیک‌های متفاوت وب**: مثل CRUD، احراز هویت، مدیریت فایل‌ها و غیره
* ✅ **پیاده‌سازی پروژه‌های کوچک و مستقل** در هر Branch برای یادگیری عملی
* ✅ **بهبود توانمندی در طراحی معماری پروژه و ساختار کد خوانا و قابل نگه‌داری**

---

## 🏗️ ساختار پروژه

* هر **Branch** شامل یک پروژه مستقل با موضوع آموزشی متفاوت است
* استفاده از **Django** به همراه **ORM داخلی آن** برای مدیریت پایگاه داده
* طراحی **رابط کاربری ساده و قابل فهم** با HTML و CSS (در پروژه‌های مرتبط با فرانت‌اند)
* تمرین **کار با قالب‌ها، فرم‌ها و مدیریت مسیرها (URLs)** در Django

> مثال Branch‌ها:
>
> * `branch_auth` → آموزش سیستم ورود و ثبت‌نام کاربران
> * `branch_crud` → تمرین عملیات CRUD روی مدل‌ها
> * `branch_blog` → ساخت بلاگ ساده با قابلیت مدیریت پست‌ها

## ⚙️ نحوه استفاده

### 1. کلون کردن مخزن

```bash
git clone https://github.com/KhazaeiAmir110/help_django.git
```

### 2. ورود به پوشه پروژه

```bash
cd help_django
```

### 3. انتخاب Branch مورد نظر

```bash
git checkout branch_name
```

### 4. ایجاد محیط مجازی

```bash
python -m venv venv
source venv/bin/activate   # در ویندوز: venv\Scripts\activate
```

### 5. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 6. اجرای سرور توسعه

```bash
python manage.py runserver
```

> سپس پروژه روی آدرس زیر در دسترس خواهد بود:

```
http://127.0.0.1:8000
```

## 📂 ساختار کلی هر پروژه

```
branch_name/
│
├── manage.py            # فایل اصلی اجرای پروژه Django
├── app_name/            # اپلیکیشن اصلی پروژه
│   ├── models.py        # مدل‌ها
│   ├── views.py         # ویوها
│   ├── urls.py          # مسیرها
│   ├── templates/       # قالب‌های HTML
│   └── static/          # فایل‌های CSS و JS
├── db.sqlite3           # پایگاه داده (در صورت استفاده SQLite)
├── requirements.txt     # وابستگی‌ها
└── README.md            # مستندات پروژه
```
